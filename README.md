# Louise Nayeong Koh — Academic Homepage

Personal academic homepage published at https://sfckbrp496-sketch.github.io/.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8765
```

Then open `http://localhost:8765` in a browser.

## Editing

- `index.html`: content and links
- `styles.css`: layout, type, and dark/light colors
- `script.js`: mobile navigation and theme switch
- `assets/profile3.png`: profile photo
- `assets/pipc-logo.png`, `assets/kisa-logo.png`: work experience logos
- `assets/CV.pdf`: downloadable CV

The theme switch remembers the visitor's choice in their browser. The header stays at the top while scrolling. GitHub Pages serves the files directly; no build step is required.
